# Softronix Snake Game

A classic Snake game built with Python and Pygame. Navigate the snake, eat food, and try to get the highest score possible!

## Features

- **Classic Gameplay**: Simple and intuitive controls for a timeless gaming experience.
- **Dynamic Difficulty**: The game speed increases as you score more points, providing a continuous challenge.
- **Persistent High Score**: Your best score is automatically saved to a local file and displayed every time you play.
- **Clean UI**: Minimalist design with a clear score and high score display.
- **Responsive Controls**: Smooth movement and direction changes.

## Prerequisites

Before running the game, ensure you have Python installed on your system. You will also need the `pygame` library.

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/oe-game.git
   cd oe-game
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## How to Run

To start the game, simply run the `game.py` script:

```bash
python game.py
```

## Controls

- **Arrow Keys**: Move the snake (Up, Down, Left, Right).
- **'R' Key**: Restart the game after a "Game Over".
